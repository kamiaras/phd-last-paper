### Notation

- Do not invent new notation. Reuse the symbols already used in the paper, in the same roles.
- Stay consistent with existing style (fonts, subscripts, time indices, operator names).
- If a new symbol is unavoidable, pick one that is not already used, and keep its style aligned with the rest of the paper. Never overload an existing symbol.

### Terminology

- Do not invent terms. Use the names already used in the paper.
- If a concept already has a name in the manuscript (or in the baseline chapter), use that name. Do not introduce a synonym for variety.

### Language

- Write a STEM academic paper, not literature. Professional and academic, but not ornate.
- Prefer short, direct sentences. Avoid complicated wording when a simpler phrase is accurate.
- Use English where it helps the reader follow the argument (setup, hypotheses, what a step is doing). Do not replace algebra with prose.

### Mathematics

- Keep the mathematics algebra-focused. A mathematician should be able to follow a proof without filling in missing calculations.
- Show the algebra. Each displayed step should be simple to verify from the previous line (one substitution, one estimate, one cited identity).
- Do not skip “routine” algebra. Do not write “it is easy to see” in place of a step.
- Use English only when it is needed to state assumptions, point to a previous result, or say why the next algebraic step is valid.
